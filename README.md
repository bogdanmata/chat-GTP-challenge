# C/C++ Training Roadmap for Game Development and Problem Solving

## 🎯 Goal
Build strong C/C++ foundations with a focus on problem-solving and game development using Unreal Engine.

---

## ✅ Phase 1: Foundations of C/C++

### 1. Basic Syntax & Structure
- `main()`, variables, data types
- Input/output: `cin`, `cout`, `printf`, `scanf`
- Control flow: `if`, `switch`, `for`, `while`, `do-while`

### 2. Functions and Scope
- Function declarations and definitions
- Parameters and return values
- Call by value vs reference

### 3. Arrays & Strings
- Static arrays
- `char[]` and `std::string`
- Basic string manipulation

### 4. Pointers and Memory
- Pointer basics: `*`, `&`
- Pointer arithmetic
- Dynamic memory: `new`, `delete`, `malloc`, `free`
- Shallow vs deep copy

---

## ✅ Phase 2: Intermediate Concepts + Problem Solving

### 5. Structures and Enumerations
- `struct`, `enum`, and nested structures
- Using structs for game-like objects

### 6. Dynamic Memory & Data Structures
- Linked lists, stacks, queues
- Arrays vs `std::vector`

### 7. Standard Template Library (STL)
- Containers: `vector`, `map`, `set`, `pair`
- Iterators and algorithms (`sort`, `find`, etc.)

### 8. Object-Oriented Programming (OOP)
- Classes, constructors, destructors
- Inheritance and polymorphism
- `this` pointer, `virtual`, `override`

### 9. Problem-Solving Practice
- Easy/Medium Leetcode problems
- Logic used in grid systems, collision, basic AI

---

## ✅ Phase 3: Advanced Topics + Unreal Engine Prep

### 10. Advanced C++
- Templates and metaprogramming basics
- Smart pointers: `unique_ptr`, `shared_ptr`
- Namespaces, `static`, `inline` functions
- File I/O
- Exception handling

### 11. Build Systems and Tools
- Compiling with `g++`, `clang++`, MSVC
- Build tools: `make`, `CMake`
- Debugging: `gdb`, `valgrind`, Visual Studio debugger

### 12. Unreal Engine C++ Basics
- `UCLASS`, `UPROPERTY`, `UFUNCTION`
- Gameplay framework: `AActor`, `APawn`, `ACharacter`
- Creating custom game logic in C++
- Integrating Blueprints with C++

---

## ✅ Phase 4: Projects + Game Dev

### 13. Mini Projects
- Console games: Snake, Tetris, Tic-Tac-Toe
- Simple physics simulation
- Custom 2D level loader or engine

### 14. Unreal Engine Game Project
- First-person or third-person base game
- C++ gameplay elements (weapons, inventory, etc.)
- Handling scenes, inputs, sound, animation

### 15. Best Practices & Performance
- Clean code, RAII, memory safety
- Performance tuning, profiling
- Introduction to multithreading

---

## 🛠️ Tools

- **IDEs**: Visual Studio, CLion, VS Code
- **Compilers**: MSVC, g++, clang++
- **Unreal Engine**: Game engine with native C++
- **Problem Solving**: Leetcode, HackerRank

---

## 📌 Tips
- Practice consistently (even 30–60 min daily adds up)
- Focus on projects to reinforce knowledge
- Keep track of learning with version control (Git)
- Review and refactor old code regularly

---

Happy coding and game building! 🚀
